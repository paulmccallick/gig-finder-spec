# Implementation Map

This map connects independently referenced specification statements to the
current source and verification locations. Paths use the locally registered
`app` repository reference. Resolve them with `./gf-ref show app::<path>` or
`./gf-ref check app::<path>`. This file is mutable: update locations when
implementation or tests move, while preserving statement IDs.

An empty verification cell means no focused test location has been recorded.
It does not mean the behavior is untested. A `not-run` note records that a
source inspection did not execute the referenced tests. Known disagreement
between a statement and implementation belongs in the discrepancy column
until deliberately resolved.
